## 2. 项目背景


本项目围绕“六轴工业机器人嵌入式运动控制固件开发与仿真验证”展开，依托 ARM Cortex-M4 MCU 仿真环境和 PyBullet 机器人仿真平台，构建一套完整的工业机器人控制开发框架，从系统架构、驱动封装、通信协议、运动学算法、任务调度到仿真验证进行工程化设计与实现。


## 3. 项目目标

本项目的总体目标为构建一套可扩展、可验证、可维护的六轴工业机器人嵌入式运动控制软件框架，完成从底层驱动到上层控制的闭环开发流程。

具体目标如下：

1. 掌握 ARM Cortex-M4 MCU 的嵌入式软件开发方法，熟练应用 C 语言进行底层驱动和任务开发；能运用实时操作系统进行多任务设计。
2. 深入理解并推导六轴工业机器人运动学公式，并完成嵌入式端运动学求解和运动控制算法实现。
3. 掌握嵌入式系统与仿真环境交互方法，具备完整仿真链路模拟系统集成和问题排查修复能力。
4. 输出一套能用于实际典型工业场景功能的可运行六轴工业机器人运动嵌入式固件。
5. 通过本仓库实现代码、设计文档、使用说明书的标准化交付。


## 4. 项目流程


### 4.1 环境搭建与系统方案设计


- 了解工业机器人控制系统的常见分层架构；
- 确定嵌入式控制软件的模块边界和接口设计；
- 搭建 ARM Cortex-M4 模拟开发环境；
- 完成 FreeRTOS 基础工程模板构建；
- 引入 PyBullet 与 UR5 模型，完成仿真环境初始化；
- 确定嵌入式端与仿真端的通信方式与帧结构。


### 4.2 外设驱动与通信模块开发


- UART 收发驱动、环形缓存设计；
- GPIO 电平控制和定时器周期中断；
- 通信帧缓存、校验与解析逻辑；
- 运动指令、参数配置和状态查询处理；
- 关节电机抽象接口设计，用于屏蔽底层硬件差异。
- 各模块单元测试


### 4.3 运动学求解算法实现


- UR5 DH 参数分析与坐标系定义；
- 正运动学齐次变换矩阵实现；
- 逆运动学求解与多解筛选；
- 关节限位约束、奇异点判定与误差处理；
- 运动学算法的嵌入式实现与测试验证。


### 4.4 轨迹规划与运动控制


- 三次/五次多项式轨迹规划；
- 梯形速度曲线规划；
- 直线和圆弧插补；
- 单关节 PID 位置闭环控制；
- 任务调度与多任务实时性设计。


### 4.5 系统集成与功能扩展


- 模块联调；
- 任务优先级与实时性优化；
- 工业场景避障逻辑设计；
- 稳定性调试和故障排查；
- 资源占用和内存优化。


## 5. 预期成果与交付形式

项目最终成果将体现为以下几个层面的交付：

- 可编译运行的嵌入式固件工程；
- 与仿真环境配套的协议和控制脚本；
- 完整的系统设计文档与接口说明；
- 功能测试、稳定性验证和性能分析报告；
- 面向后续真实硬件移植和控制算法扩展的框架设计。

### docs/
用于存放工程设计文档与开发说明，当前内容包括：

- communication_protocol.md：通信协议约定
- environment_setup.md：环境搭建与使用说明
- system_design.md：系统总体设计、接口定义和模块分层说明
- test_report.md：unity测试框架下16个单元测试用例测试报告
- kinematics.md：运动学初步推导

### external/
外部依赖目录，当前包含 Bullet3 仿真引擎等第三方模块。

### firmware/
嵌入式固件主体，包含：

- app/：应用层逻辑、任务与状态机
- bsp/：板级支持层，时钟、GPIO、定时器等抽象
- drivers/：协议、UART、通信驱动等
- lib/：公共库或辅助能力
- config/：编译链接与内存布局配置
- tests/：固件测试代码和验证脚本
- third_party/：FreeRTOS 等第三方组件

### simulation/
仿真端目录，包含：

- models/：UR5 等机器人模型与来源资料
- scenes/：仿真场景文件
- scripts/：加载机器人、控制验证和脚本工具
