# UR5 运动学定义与推导

## 1. 适用范围与模型基线

仿真使用的 [ur5.urdf](../simulation/models/ur5/ur5.urdf) 是经典 UR5（非 UR5e）。本项目采用与该 URDF 几何等价的名义标准 DH 解析模型，不代表某一台实机的标定参数。若替换 URDF，必须重新核对关节链、固定变换、DH 参数和限位。

标准 DH 参数采用米和弧度，参数顺序为 `a、d、alpha`：

| 关节 | `a` (m) | `d` (m) | `alpha` |
|---|---:|---:|---:|
| 1 | 0 | 0.089159 | `+pi/2` |
| 2 | -0.425 | 0 | 0 |
| 3 | -0.39225 | 0 | 0 |
| 4 | 0 | 0.10915 | `+pi/2` |
| 5 | 0 | 0.09465 | `-pi/2` |
| 6 | 0 | 0.0823 | 0 |

六个活动关节顺序固定为 `shoulder_pan`、`shoulder_lift`、`elbow`、`wrist_1`、`wrist_2`、`wrist_3`，旋转轴均为各自局部 `+z` 轴。

## 2. 坐标系、方向与变换约定

采用右手系、列向量和主动变换：`T_A_B` 表示把 `{B}` 中的点变换到 `{A}`，即 `p_A = T_A_B p_B`。`R_A_B` 的列向量是 `{B}` 的三个轴在 `{A}` 中的表达。旋转均为绕当前局部轴的右手正角，长度单位为 m。

| 坐标系 | 定义和方向 |
|---|---|
| `{W}` | PyBullet 世界系；固定基座时与 `base_link` 重合，`X` 前、`Y` 左、`Z` 上。 |
| `{B}` | 解析基座系，取 `base_link_inertia`/控制器 `Base` 方向；相对 `{W}` 为绕 Z 轴旋转 `pi`。对外若使用 `base_link`，必须显式乘这个固定变换。 |
| `{0}...{6}` | 标准 DH 帧；`z_(i-1)` 是第 `i` 个关节轴，`x_i` 是相邻关节轴的公法线方向。6 个变量依次为 `q1...q6`，正方向均为局部 `+z` 右手正转。 |
| `{F}` | URDF `flange`，法兰安装点；相对 `wrist_3_link` 的固定姿态为 `rpy=(0,-pi/2,-pi/2)`。 |
| `{E}` | URDF `tool0`，默认末端工具系；相对 `flange` 的固定姿态为 `rpy=(pi/2,0,pi/2)`，默认无额外平移。 |

解析 FK 输出定义为 `T_B_E`。实现可先计算 DH 链 `T_B_6`，再乘固定的 DH-to-tool0 外参 `T_6_E`；该外参必须通过零位 FK 与 URDF 对齐测试确定，不能凭视觉方向猜测。不得在接口中混用 `{W}`、`{B}` 或 `{F}` 的位姿。

## 3. 单关节标准 DH 齐次矩阵

标准 DH 依次执行 `Rot(z_(i-1), theta_i)`、`Trans(z_(i-1), d_i)`、`Trans(x_i, a_i)`、`Rot(x_i, alpha_i)`。令 `theta_i=q_i+theta_i0`，本项目 `theta_i0=0`：

$$
A_i(q_i)=T_{i-1,i}=\begin{bmatrix}
 c_{\theta_i} & -s_{\theta_i}c_{\alpha_i} & s_{\theta_i}s_{\alpha_i} & a_i c_{\theta_i}\\
 s_{\theta_i} & c_{\theta_i}c_{\alpha_i} & -c_{\theta_i}s_{\alpha_i} & a_i s_{\theta_i}\\
 0 & s_{\alpha_i} & c_{\alpha_i} & d_i\\
 0&0&0&1
\end{bmatrix}
$$

其中 `c_x=cos(x)`、`s_x=sin(x)`。六轴连乘为：

$$T_{B,6}(q)=A_1A_2A_3A_4A_5A_6,\qquad T_{B,E}=T_{B,6}T_{6,E}.$$

矩阵乘法顺序不可交换。FK 应同时返回 `R_B_E` 和 `p_B_E`，并用 `R^T R=I`、`det(R)=1` 检查旋转矩阵，允许明确的浮点容差。

## 4. 角度与末端位姿格式

- 固件算法层、通信 payload、关节限位和三角函数统一使用 `float` 弧度；速度为 rad/s，加速度为 rad/s2，长度为 m。角度转换只允许在 UI/日志边界进行。
- 关节数组顺序固定为 `q[0..5] = [shoulder_pan, shoulder_lift, elbow, wrist_1, wrist_2, wrist_3]`，与 URDF 的 6 个活动关节顺序一致。
- `pose` 使用 4x4 行主序齐次矩阵 `T_B_E`；位置是 `T[0:3,3]`，旋转是左上 3x3。内部接口不使用欧拉角。
- 调试文本可使用 `x,y,z,roll,pitch,yaw`，单位为 `m,rad`，且明确为 ZYX 展示格式：`R=Rz(yaw)Ry(pitch)Rx(roll)`。`pitch=+-pi/2` 附近有万向节锁，不能作为唯一内部表示。

## 5. 八组逆解的解析流程

UR5 的后三轴构成球腕。给定 `T_B_E=[R_B_E,p_B_E]`，先求 `T_B_6=T_B_E T_{6,E}^{-1}`，再由肩部、肘部、腕部三个二值分支生成最多 8 组：肩部 `sigma_s`、肘部 `sigma_e`、腕部翻转 `sigma_w`，组合为 `2 x 2 x 2`。

1. **腕心和肩部**：`p_wc = p_B_6 - d_6 R_B_6 [0,0,1]^T`。令 `rho=sqrt(x_wc^2+y_wc^2)`，对两个 `sigma_s` 用 `atan2` 与 `acos` 解 `q1`；符号取决于本节 DH 的 `d4` 约定，代码必须用 FK 回代确认。
2. **肘部**：固定 `q1`，将腕心投影到 `{1}` 平面，按余弦定理求 `q3=atan2(sigma_e*sqrt(max(0,1-D^2)),D)`，再用两次 `atan2` 求 `q2`。`|D|>1+tol` 表示无解，`|D|` 接近 1 标记肘部奇异。
3. **腕部**：由 `R_3_6=R_B_3^T R_B_6` 求 `q4,q5,q6`。`q5` 的正负分支对应腕部翻转；当 `|sin(q5)|<tol` 时，`q4+q6` 只有组合值可确定，应按当前关节位置选连续解并标记 `ROBOT_ALGO_SINGULAR` 风险。
4. **验算去重**：每组先将 `q+2kpi` 归一化到最接近当前状态的等价值，再计算 FK。仅保留位置误差和旋转角误差均在容差内的候选，并去掉数值重复项；`acos/asin` 前 clamp 到 `[-1,1]`，但超过容差必须返回无解。

解选择优先级为：全部关节满足限位，其次距离当前关节状态的加权平方和最小，再其次远离奇异面。`robot_kinematics_ik()` 返回全部候选及 `count`，不应静默只返回第一组；无候选返回 `ROBOT_ALGO_NO_SOLUTION`。

## 6. 关节限位规则

位置限位以弧度闭区间执行，来自当前 URDF：

| `q` | 关节 | 位置范围 | 速度上限 |
|---:|---|---:|---:|
| `q1` | shoulder_pan | `[-2pi, 2pi]` | `pi` rad/s |
| `q2` | shoulder_lift | `[-2pi, 2pi]` | `pi` rad/s |
| `q3` | elbow | `[-pi, pi]` | `pi` rad/s |
| `q4` | wrist_1 | `[-2pi, 2pi]` | `pi` rad/s |
| `q5` | wrist_2 | `[-2pi, 2pi]` | `pi` rad/s |
| `q6` | wrist_3 | `[-2pi, 2pi]` | `pi` rad/s |

候选解、MOTION 命令入口和单关节目标设置必须执行同一规则：有限数检查 -> 弧度输入 -> 位置闭区间检查 -> 速度/加速度非负及上限检查。越界值拒绝并返回 `ROBOT_ALGO_JOINT_LIMIT` 或映射后的应用层限位错误，不自动截断；仅在求解内部允许按 `q+2kpi` 归一化，归一化后仍须在闭区间内。边界值可等于限位，但轨迹规划不得因数值误差推出边界。

## 7. FK 校验

为确认解析模型同时满足 URDF 的零位坐标和 PyBullet 的运行时正解，使用与第 3 节相同的标准 DH 矩阵计算 `T_B_E`，并与
`simulation/models/ur5/ur5.urdf` 加载后的 `tool0` 位姿比较。PyBullet 中先将六个活动关节通过
`resetJointState()` 设置为测试角度，再用 `getLinkState(..., computeForwardKinematics=True)` 读取
`tool0` 位姿；读取结果从 `{W}` 变换到 `{B}`，其中 `T_W_B=R_z(pi)`。位置误差定义为

$$
e_p=\left\|p_{B,E}^{\mathrm{DH}}-p_{B,E}^{\mathrm{PyBullet}}\right\|_2
$$

姿态误差定义为相对旋转角：

$$
e_R=\arccos\left(\operatorname{clamp}\left(\frac{\operatorname{tr}((R^{\mathrm{DH}})^T R^{\mathrm{PyBullet}})-1}{2},-1,1\right)\right)
$$

### 7.1 零位对标 URDF

测试角度为 `q=[0, 0, 0, 0, 0, 0] rad`。由零位反推的 `T_6_E` 为单位阵（误差仅来自浮点舍入），因此文档中的 DH 链可直接与 URDF 的 `tool0` 对齐。
