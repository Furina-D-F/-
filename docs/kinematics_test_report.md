# 运动学与控制精度测试

## 1. 测试范围

| 项目 | 内容 |
|---|---|
| 被测对象 | `firmware/app/kinematics.c`、`cartesian_trajectory.c`、`artificial_potential_field.c`、`joint_pid.c` |
| 基准实现 | Robotics Toolbox Python 1.4.2，按文档标准 DH 参数构造 `DHRobot` |
| 运行环境 | host `ctypes` 调用（与 ARM 固件共用同一份源码）；闭环用例为 ARM Cortex-M4 + FreeRTOS + QEMU `mps2-an386` 与 PyBullet 的处理器在环 |
| 编译 | C11，`-Wall -Wextra -Werror` |
| 结论 | 全部通过，各项精度余量 3～15 倍 |

## 2. 运动学精度

512 组随机位姿，分为常规工作区、接近关节边界、限位附近、q3/q5 近奇异区四层，各约 128 组。

| 指标 | 均值 | P95 | 最大值 |
|---|---:|---:|---:|
| FK 位置误差 (m) | 7.57e-08 | 1.55e-07 | 2.23e-07 |
| FK 姿态误差 (rad) | 1.72e-07 | 3.34e-07 | 5.31e-07 |
| IK 位置误差 (m) | 5.00e-07 | 4.18e-07 | 1.17e-04 |
| IK 姿态误差 (rad) | 5.25e-06 | 4.84e-06 | 1.42e-03 |

- 与解析基准的一致性是双精度浮点噪声量级，且逐位可复现（同一组样本重跑结果完全相同）。
- 单次求解耗时 FK 约 5～12 us、IK 约 14～35 us（随机负载波动），量级上比基准实现快一个数量级。
- IK 候选生成成功 508/512，最优解筛选通过 497/512；未选中的 15 例全部落在 q3/q5 近奇异区（4 例候选生成失败、11 例候选全为奇异解），非奇异区内无失败。

## 3. 关节 PID 整定

PyBullet UR5 第 1 关节，目标 `0.800 rad`，采样 240 Hz，增量式 PID（输出限幅 2.0 rad/s、
积分限幅 1.0、死区 0），评分 `RMSE + 0.5 × 最大超调 + 稳态误差`。

| Kp | Ki | Kd | RMSE (rad) | 最大超调 (rad) | 稳态误差 (rad) |
|---:|---:|---:|---:|---:|---:|
| 2.500 | 0.300 | 0.025 | 0.2644 | 0.0288 | 0.0288 |
| 3.000 | 0.350 | 0.030 | 0.2903 | 0.0000 | 0.0871 |
| 3.500 | 0.400 | 0.035 | 0.3259 | 0.0000 | 0.1702 |

推荐 `Kp = 2.5、Ki = 0.3、Kd = 0.025`。该组参数适用于当前模型、输出限幅与 240 Hz 采样；
更换负载、摩擦或控制周期后需重新整定（脚本会打印全部候选组）。

## 4. 笛卡尔轨迹闭环性能

PyBullet 的关节位置/速度经 `SIMULATION_STEP` 注入固件，固件在同一帧内完成轨迹插补、APF
修正、周期 IK 与 PID 并返回速度指令，PyBullet 以 `VELOCITY_CONTROL` 作为外部执行器执行，
构成处理器在环闭环。1.0 倍速对应 2 s 轨迹，力矩上限取官方 `[150,150,150,28,28,28]` N·m。

验收标准与实测（0.5/1.0/1.5 倍速 × line/arc 共 6 个用例）：

| 指标 | 验收标准 | 实测范围 |
|---|---:|---:|---:|
| 轨迹位置 RMSE | ≤ 0.5 mm | 0.039～0.080 mm |
| 稳态位置误差 | ≤ 0.3 mm | 0.020～0.033 mm |
| 轨迹姿态 RMSE | ≤ 0.25° | 0.037～0.041° |
| 稳态姿态误差 | ≤ 0.15° | 0.047° |

每个用例 235～501 个 `SIMULATION_STEP`，全程 `state=RUNNING`、`error=0`，无 IK 失败、
无碰撞。

## 5. 任务级定位精度

4 个工业搬运场景各重复 3 次：末端到位误差 1.18～2.64 mm、抓取-放置精度 0.82～1.75 mm，
APF 避障段的最大路径偏移 59～137 mm（场景与流程见[系统测试文档](system_test_report.md)）。
