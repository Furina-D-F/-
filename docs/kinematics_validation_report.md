# UR5 运动学精度对比分析

- 测试样本：128 组，随机种子：20260911
- 基准：Robotics Toolbox Python `1.4.2`，使用项目文档中的精确标准 DH 参数构造 `DHRobot`。
- 被测实现：`firmware/app/kinematics.c`，通过 host `ctypes` 调用，与 ARM 固件共用源码。
- 样本分层：常规工作区、接近关节边界、限位附近、q3/q5 近奇异区域，各占约四分之一。
